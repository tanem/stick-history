# Security policy

## Supported versions

Only the latest release is supported. A fix goes out in a new release, and earlier releases are not patched.

## Reporting a vulnerability

Report a vulnerability through GitHub's [private vulnerability reporting](https://github.com/tanem/stick-history/security/advisories/new), not in a public issue. Expect a first reply within a week.

## Scope

A crash, a hang or excessive memory use caused by a crafted `export.pdb` is in scope.
